# QuantumFlow AI Gold Prediction

QuantumFlow AI is a high-performance gold prediction platform designed for short-term trading. It leverages real-time WebSocket data from major exchanges and processes it through a TensorFlow.js-powered prediction engine.

## Architecture
- **Frontend**: React, Vite, TypeScript, Tailwind CSS, Recharts, Zustand.
- **Backend**: Node.js, Express, Socket.io, TensorFlow.js, MongoDB.
- **Data Source**: Binance WebSocket API.
